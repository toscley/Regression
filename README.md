This notebook explores regression techniques across four progressively complex datasets. It begins with Linear Regression on the California Housing dataset to predict median house prices, evaluating results with MAE, MSE, RMSE, and R², then improves the model through simple feature engineering (e.g., rooms-per-age, population-per-household ratios). It then moves to a Salary dataset, applying a Gradient Boosting Regressor loaded from Google Drive. The core of the notebook is a Kaggle House Price Prediction exercise, where it performs substantial data cleaning (dropping high-missing columns, imputing means/medians/modes), one-hot encodes categorical features, log-transforms the skewed target variable, and fits a Linear Regression model, such as generating a submission CSV of predicted sale prices. Finally, it repeats the same Kaggle pipeline using a Gradient Boosting Regressor (referred to as "XGBoost" in the notebook, though it actually uses scikit-learn's GradientBoostingRegressor) to compare performance against the linear baseline.
